# Ministry of Fisheries Website

Official website and content management system project for the Sri Lanka Ministry of Fisheries, Aquatic and Ocean Resources.

## Project structure

- `frontend` — Next.js public website
- `backend` — Python Django API and staff administration panel
- `docs` — project documentation

## Technology stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- Python
- Django
- Django REST Framework

### Database

- PostgreSQL
