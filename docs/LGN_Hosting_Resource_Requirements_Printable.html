01 විධායක සාරාංශය සහ අරමුණ (Executive Summary)

ධීවර, ජලජ හා සාගර සම්පත් අමාත්‍යාංශයේ නව නිල ත්‍රෛභාෂා වෙබ් අඩවිය සහ අමාත්‍යාංශ කාර්ය මණ්ඩල අන්තර්ගත කළමනාකරණ පද්ධතිය (Staff CMS) සාර්ථකව නිර්මාණය කර අවසන් කර ඇත. මෙම වෙබ් පද්ධතිය ශ්‍රී ලංකා ඩිජිටල් සංවර්ධන ප්‍රමිතීන්ට (SLDDS) අනුකූලව ගොඩනගා ඇති අතර, අමාත්‍යාංශ තොරතුරු, මහජන සේවා, සංඛ්‍යාලේඛන වාර්තා, ටෙන්ඩර්, රැකියා අවස්ථා සහ මාධ්‍ය නිවේදන 24/7 බාධාවකින් තොරව ජනතාව වෙත ලබා දීම සඳහා Lanka Government Cloud (LGC / LGN) යටිතල පහසුකම් මත සත්කාරකත්වය (Hosting) ලබා දෙන ලෙස ගෞරවයෙන් ඉල්ලා සිටිමු.

02 තාක්ෂණික ගෘහ නිර්මාණ ශිල්පය (Technology Architecture)

පද්ධතිය නවීන, ස්ථර 3 කින් සමන්විත Decoupled Architecture ආකෘතියකින් නිමවා ඇත:

  • Frontend Web Tier: Next.js 15 (Node.js 20+ LTS runtime, React 19, TypeScript, Tailwind CSS). Server-Side Rendering (SSR) මඟින් අධිවේගී පිටු සැකසීම.
  • Backend REST API & Staff CMS Tier: Python 3.11+ / Django 5.x, Django REST Framework (DRF), Gunicorn WSGI Application Server.
  • Database Tier: MySQL Server 8.0+ (InnoDB Engine, utf8mb4_unicode_ci Trilingual Sinhala/Tamil/English Support).
  • Reverse Proxy & Security: Nginx Web Server (SSL Termination, HTTP/2, Gzip/Brotli Compression, Micro-caching).

05 උපස්ථ සහ ආපදා කළමනාකරණය (Backup & Disaster Recovery)

  • දෛනික දත්ත සමුදාය උපස්ථය (Daily DB Backup): සෑම දිනකම මධ්‍යම රාත්‍රී 12:00 ට ස්වයංක්‍රීය MySQL Database Dump.
  • දත්ත රඳවා ගැනීමේ ප්‍රතිපත්තිය (Retention Policy):
    • දිනපතා උපස්ථ (Daily Backups): දින 7ක්
    • සතිපතා උපස්ථ (Weekly Backups): සති 4ක්
    • මාසික උපස්ථ (Monthly Backups): මාස 12ක්
  • Media Files Backup: සතිපතා ලේඛන සහ ඡායාරූප වෙනම Cloud Storage එකකට පිටපත් කිරීම.
  • RTO (Recovery Time Objective): පැය 2ක් ඇතුළත සේවාව යථා තත්ත්වයට පත් කිරීම.
  • RPO (Recovery Point Objective): උපරිම පැය 24ක දත්ත සීමාව.
